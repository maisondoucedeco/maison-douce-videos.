# Maison Douce — vidéos publiques

Ce dépôt ne contient que le générateur vidéo public et les vidéos destinées à être publiées.

**Ne jamais placer de clé API, de jeton Buffer ou de données privées dans ce dépôt.**

L'automatisation de publication et les secrets demeurent dans le dépôt privé `maison-douce-automation`.

Le workflow **Render public Maison Douce video** crée un MP4 vertical, l'enregistre sous un nom unique dans `videos/` et fournit une adresse publique brute pour Buffer. Ce n'est **pas** une publication Instagram/TikTok.

La première exécution est manuelle. Aucun contenu social n'est envoyé sans validation.
